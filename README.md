# 🌷 Bloom — Your Little Focus Corner

A cozy productivity website designed to help you organize your tasks, stay focused, take mindful breaks, and reflect on your day.

Bloom is a personal productivity space that brings task management, focus sessions, music, and journaling together in one calming interface.

## ✨ Features

### 🏡 Home

A welcoming dashboard to help you get started with your day.

### ✅ My Tasks

- Add and manage daily tasks.
- Organize tasks by category.
- Track task completion.
- Store task data using browser `localStorage`.

### ⏳ Focus Room

- Pomodoro-style focus timer.
- Focus sessions and break modes.
- Customize timer durations to suit your needs.

### 🎧 Music Corner

- Search for songs and artists on Spotify.
- Embed your personal Spotify playlist.
- Save your playlist link in browser `localStorage`.

### 📖 My Journal

A personal space to write down thoughts, daily reflections, and little moments.

### 📊 My Progress

- View total tasks, completed tasks, and remaining tasks.
- Track overall task completion.
- See progress by task category.

### 🌙 Additional Features

- Light and dark themes.
- Responsive layout for different screen sizes.
- Browser-based data persistence using `localStorage`.

## 🛠️ Built With

## 🚀 Getting Started

### Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/there080922/bloom-prototype.git
   ```

2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension for a smoother development experience.

### Deploy with Vercel

1. Sign in to [Vercel](https://vercel.com/).
2. Import the Bloom repository from GitHub.
3. Select **Other** as the framework preset.
4. Configure the project as a static website.
5. Click **Deploy**.

## 💾 Data Storage

Bloom uses browser `localStorage` to save certain information, including tasks, theme preferences, timer settings, and the saved Spotify playlist link.

Stored data is specific to the browser and origin being used. It is not automatically synchronized across devices or browsers.

## 🎵 Spotify Integration

Bloom allows users to search for songs on Spotify and embed a personal playlist using a Spotify playlist link.

Playback and playlist availability depend on Spotify's own features and access restrictions.
